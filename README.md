## 代码目录约定

**十天一个文件夹，每段练习一个 .py 文件。**

```
code/
├── days-01-10/
│   ├── d01_hello.py
│   ├── d01_types.py
│   ├── d02_string.py
│   └── ...
└── days-11-20/
    ├── d11_...
    └── ...
```

1. **文件夹**：`days-01-10`、`days-11-20`、`days-21-30`……按十天切一段
2. **文件名**：`d<两位天数>_<主题>.py`，例如 `d01_hello.py`、`d02_types.py`
   - `d01` 表示第 1 天，不是第 1 个练习——同一天有多个练习就写成 `d01_hello.py`、`d01_types.py`
   - 主题用英文小写 + 下划线，不用中文（避免路径编码问题）
   - 序号补零到两位，这样文件名排序就是学习顺序
3. **练习代码一律保留，不删。** 这个仓库的价值就是完整的学习轨迹——一个月后回头看第一天的代码，是判断进步最直观的方式
4. 唯一例外：故意制造报错的演示代码，加一行注释说明保留原因

## 每日笔记写什么

固定六段：今天做了什么 / 学到的一个概念 / 代码链接 / 卡住的地方 / 明天 / 一个问题。

**「卡住的地方」是整篇最重要的部分**——它记录的是真实的学习痕迹，也是三个月后复习时的盲区地图。

1. 不上传任何实验原始数据、频段指标、项目细节
