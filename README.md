## 结构说明

```
notes/     每日笔记（按月份分目录）+ 每周总结
code/      每日练习代码，一天一个目录
resources.md  收藏的链接、论文、工具
```

## 每日笔记写什么

固定六段：今天做了什么 / 学到的一个概念 / 代码链接 / 卡住的地方 / 明天 / 一个问题。

**「卡住的地方」是整篇最重要的部分**——它记录的是真实的学习痕迹，也是三个月后复习时的盲区地图。

## 三条原则

1. 不上传任何实验原始数据、频段指标、项目细节
2. 不上传自己看不懂的代码（AI 生成的可以进，但必须逐行读懂）
3. 不做无信息的打卡（一次有内容的提交胜过十次空提交）
